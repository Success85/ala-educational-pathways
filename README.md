# ALA Educational Pathways

A faculty-facing web app that shows how students from every African education system are likely to transition into African Leadership Academy's Cambridge programme: what they bring, where they may struggle, and how to support them.

Open the app and start using it. There is no login, no database and nothing to upload: all content is built in.

## Run it

You need Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## What's inside

| Page | What it does |
| --- | --- |
| Explore | Find a country by name or region |
| Country | Education system, stages, exams, grading, entry points, notes on reforms, and readiness for every ALA subject |
| Subject report | For one country and subject: transition profile for each entry point, "Why this rating?" for every rating, Cambridge benchmark, faculty support, matching unit plans, research team findings where they exist. Print or download |
| Subjects | Each ALA subject's Cambridge or ALA benchmark, and readiness of all 54 countries, sortable by who needs most support |
| Systems | The eight education traditions (WAEC, East African, O-Level/IGCSE, South African NSC, Francophone, Lusophone, Arabophone, Hispanophone) |
| Compare | Up to four countries side by side for one subject, with the biggest differences; plus the research team's Francophone comparison |
| Student profile | Enter one student's country, entry point, language, subjects, national results and background; get a printable transition profile with cross-subject priorities. Profiles can be saved in the browser |
| Grade guide | WASSCE, KCSE, UCE, CSEE, NESA, ZIMSEC, NSC, Baccalauréat and more, with a result reader |
| Unit plans | Example bridging and core units, filtered by the gap they address |
| Search | Strengths, challenges, transition gaps and recommendations by country, subject or department |
| About | Where the content comes from and how profiles are built |

## Where the content comes from

- **Research team findings**: the Burkina Faso Business Studies and Language Transition sheets and the Tunisia–Burkina Faso Francophone comparison, exactly as written by the research team. Stored in `src/data/research.json`.
- **Country profiles**: compiled from national examination bodies, ministries and public sources (listed on each country page and the About page). Stored in `src/data/countries.ts`.
- **Indicative profiles**: generated by `src/lib/engine.ts` from the education tradition, subject, country, entry point and (in the student tool) the student's own background. Every step is shown under "Why this rating?".
- **Unit plans**: illustrative examples in `src/data/unitPlans.ts`, not official ALA documents.

## Updating content

All content is plain TypeScript or JSON in `src/data/`:

- `countries.ts`: one entry per country (system, exams, grading, entry points, notes, adjustments)
- `traditions.ts`: the eight education traditions and their typical starting points
- `subjects.ts`: subjects, Cambridge benchmarks, what each readiness area means and the matching support
- `grading.ts`: national grading scales
- `unitPlans.ts`: example unit plans
- `research.json`: research team findings

`src/lib/research.ts` contains importers that turn a pasted research sheet or comparative matrix into the JSON format used in `research.json`.

## Publish it

`npm run build` creates a static site in the `out` folder. Upload that folder to any static host:

- **Vercel**: import the GitHub repository; no settings needed.
- **Netlify**: drag the `out` folder onto app.netlify.com/drop.
- **GitHub Pages** or any web server.
